# Python Practice & Development Record

Pythonの基礎習得から自動化ツールの開発、そしてWebアプリケーション開発への展開を目指す成長と技術検証の記録リポジトリです。

---

## 📂 ディレクトリ構成と機能概要

### 🚚 1. 配送時間記録・集計ツール (`delivery/`)
実務での利用や自動化を意識し、ログの記録から統計・テストまでを一連のパイプラインとして実装しています。

* **`main.py`**: 配送時間の算出および記録用メインスクリプト。
    * 開始・終了時間から配送時間を自動計算し、`delivery_log.txt` へ日付・曜日付きで記録。
    * CUIツールとしての利便性を考慮し、**コマンドライン引数**と**対話型入力**の両方に対応。
* **`logic.py`**: 配送時間の計算ロジック（ビジネスロジックの分離）。
* **`summary.py`**: 蓄積された配送ログを読み込み、合計・平均配送時間を集計して出力。
* **`weekly_summary.py`**: 配送ログを曜日別に集計。コンソール上に見やすい**テキストグラフ**で可視化する機能。
* **`test_delivery.py`**: `unittest` モジュールを用いた、ロジック部分のユニットテストコード。

### 🌐 2. スクレイピング・自動化検証 (`scraping202605/`)
* スクレイピングおよび各種自動化ツールの検証記録、動作デモ動画を格納。
