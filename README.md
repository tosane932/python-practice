Pythonの基礎習得から自動化ツールの開発、そしてWebアプリケーション開発への展開を目指す学習記録リポジトリです。

## ディレクトリ構成と機能概要

### 配送時間記録・集計ツール (`delivery/`)
配送時間の記録から集計・テストまでを、役割ごとにファイルを分けて実装しています。

- **`main.py`**: 配送時間の算出・記録用スクリプト。開始・終了時間から配送時間を計算し、`delivery_log.txt`に日付・曜日付きで記録。コマンドライン引数と対話型入力の両方に対応。
- **`logic.py`**: 配送時間の計算ロジック。
- **`summary.py`**: 配送ログを読み込み、合計・平均配送時間を集計して出力。
- **`weekly_summary.py`**: 配送ログを曜日別に集計し、テキストグラフ付きで表示。
- **`test_delivery.py`**: `unittest`によるロジック部分のユニットテスト。

### スクレイピング・自動化検証 (`scraping202605/`)
RSSスクレイピングおよび自動化ツールの検証記録、動作デモ動画を格納。
